# Aero-Graph-minor-project

## AeroGraph — Interactive Flight Route Planner & Graph Algorithm Visualizer

A professional aviation operations dashboard and flight route planner built using Graph Theory, Dijkstra's Algorithm, Prim's Minimum Spanning Tree (MST), and K-Shortest Paths.

### ✈️ Features
- **Route Optimization**: Dijkstra's Algorithm for finding the optimal flight paths based on distance, cost, and time.
- **Network Optimization**: Prim's Algorithm for calculating Minimum Spanning Tree (MST) across airline networks.
- **Alternative Routes**: K-Shortest Paths algorithm for backup flight routes and contingency planning.
- **Interactive Visualizer**: Dynamic HTML5 Canvas rendering for airport nodes and flight routes.
- **Operations Dashboard**: Aviation analytics, fleet tracking, and live route status.

### 🛠️ Tech Stack
- HTML5
- CSS3 (Responsive Dark Modern Theme)
- Vanilla JavaScript (Graph Data Structures & Algorithms)

### 🚀 Getting Started
Simply open `index.html` in any modern web browser.
