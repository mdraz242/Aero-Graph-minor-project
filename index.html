About AeroGraph — Academic Project Overview

Project Overview

AeroGraph is an advanced aviation route planning and graph optimization simulation created for the Design and Analysis of Algorithms (DAA) curriculum. It models Indian civil aviation corridors as a weighted, connected graph where airports are vertices and direct air connections are edges.

By implementing foundational algorithms (Dijkstra, Prim's, and Yen's K-Shortest) directly in pure JavaScript without external dependencies, it provides real-time visualization of algorithmic complexity, relaxation steps, and multi-objective route trade-offs.

Algorithms Implemented

  • Dijkstra's Single-Source Shortest Path: Finds optimal point-to-point flights using a custom Min-Priority Queue. Supports multi-objective optimization across Distance (km), Fare (₹ INR), and Flight Duration (hours).
  • Prim's Minimum Spanning Tree (MST): Determines the minimal total network connectivity required to interconnect all reachable Indian airports without redundant cycles.
  • Yen's K-Shortest Loopless Paths: Generates deviations at intermediate spur nodes to provide dispatchers with the top 3 alternative paths for weather or airspace bypass.

Technical Specifications

Architecture Pure HTML5, CSS3, Vanilla ES6+ JavaScript
Data Structure Adjacency List with Min-Priority Heap
Map Engine Native Procedural SVG with Geodetic Mercator / Equirectangular Projection

Airport Dataset 14 Major Indian Air Hubs (DEL, BOM, BLR, MAA, HYD, CCU, PNQ, AMD, COK, JAI, LKO, IXC, GOI, GAU)
